# android-app — Ayni Provider

Turns an Android phone/tablet into a provider on the shared-compute network. Kotlin +
Jetpack Compose UI, a foreground `ProviderService` that honours a run-policy
(charging / Wi-Fi / battery), and the Rust `provider-core` compiled to a native library
via `uniffi`.

`applicationId` = `dev.ayni.provider` (permanent — do not change after publishing).

## Layout

```
android-app/
├── build-native.sh            # cross-compile provider-core/sc-mobile + gen uniffi bindings
├── settings.gradle.kts, build.gradle.kts, gradle.properties
├── gradle/wrapper/            # pinned to Gradle 8.11.1 (AGP 8.7.3)
└── app/
    ├── build.gradle.kts       # minSdk 26, compileSdk 35, Compose, JNA (uniffi runtime)
    └── src/main/
        ├── AndroidManifest.xml
        ├── kotlin/dev/ayni/provider/
        │   ├── MainActivity.kt        # Compose: status + settings + start/stop
        │   ├── ProviderService.kt     # foreground service, policy loop
        │   ├── ProviderController.kt   # owns the native Provider, StateFlow of status
        │   ├── Config.kt              # SharedPreferences-backed settings
        │   └── Policy.kt              # charging / Wi-Fi / battery gating
        ├── java/uniffi/sc_mobile/     # GENERATED by build-native.sh (gitignored)
        └── jniLibs/<abi>/libsc_mobile.so   # GENERATED by build-native.sh (gitignored)
```

## Build

Prereqs (see `docs/DEVELOPMENT.md`): rustup with android targets, Android SDK + NDK,
`cargo-ndk`, OpenJDK 17+.

```bash
cd android-app
./build-native.sh                       # -> jniLibs + uniffi bindings  (ABIS="arm64-v8a x86_64" for emulator)
./gradlew :app:assembleDebug            # -> app/build/outputs/apk/debug/app-debug.apk
# install on a connected device / emulator:
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`build-native.sh` defaults to the `mock` backend feature set. `FEATURES=llama
./build-native.sh` builds the real llama.cpp Android backend (larger, slower — M6).

## Configure

Open the app → fill **Registration token** (an `sc_prov_…` value from
`infra/deploy-coordinator.sh`), keep the defaults for coordinator URL / manifest / pubkey
→ **Save settings** → **Start**. The service connects while charging + on Wi-Fi (both
toggleable).
